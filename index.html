    Импорт

    Файл проверяется на сервере до записи: структура, версия схемы, типы и длины полей, даты, дубликаты идентификаторов. Сначала показывается предпросмотр, запись выполняется одной транзакцией только после подтверждения.

    Экспорт

    Выгрузка содержит медицинские данные в открытом виде. Храните и передавайте файл так же осторожно, как медицинскую карту.

    Пациент и группа

    Список содержит пациентов, подходящих выбранной консилиумной группе по коду МКБ‑10.

    Оформление задним числом

    Доступны только свободные слоты, которые председатель создал задним числом.

    Причина видна председателю и заведующему отделения. Врачу показывается только отметка «Оформлено задним числом».

    Свободный слот

    Выберите свободный слот из расписания председателя.

    При создании слот закреплён. В режиме изменения можно перенести запись на другую дату и только на свободное время той же группы.

    Сведения для консилиума

    Заполняется из текущей учётной записи.

    После выбора список кодов МКБ‑10 будет отфильтрован по локализации.
