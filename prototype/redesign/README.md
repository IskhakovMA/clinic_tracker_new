# Прототип редизайна «Системы планирования»

Визуальная демоверсия для согласования. Не подключена к backend и API,
работает только на синтетических данных (`data.js`); изменения живут в
памяти вкладки и пропадают при перезагрузке. Основной интерфейс
(`index.html`, `static/`) не изменён.

## Запуск

Из корня репозитория (прототип берёт шрифты из `static/fonts.css`):

```bash
python3 -m http.server 8765 --bind 127.0.0.1
```

Открыть: <http://127.0.0.1:8765/prototype/redesign/>

## Что внутри

- Переключатель «Роль» в верхней панели: врач, заведующий, председатель
  консилиума, руководство. Разделы и кнопки видны по тем же правилам, что
  в приложении.
- Переключатель «Состояние»: данные, загрузка, пусто, ошибка.
- Кнопка с луной — светлая и тёмная тема (по умолчанию — системная).
- Клавиша `/` — фокус на поиске, `Esc` — закрыть окно.
- «ИИ-помощник» в верхней панели и «Спросить помощника» в карточке
  пациента. Это демонстрация: модель не подключена, ответы заготовлены по
  синтетическим данным в области доступа выбранной роли и помечены
  «Демо-ответ». Состояние «Ошибка» показывает недоступность помощника.
- «Сообщения» — переписка врача с пациентами по сценарию Patient Portal
  v0.5.1. Только у роли «Врач» и только по своим пациентам (лечащим врачом
  в приложении может быть только врач). Демонстрация: сообщения живут в
  этой вкладке, не доставляются пациенту, не хранятся на сервере и не
  синхронизируются с мобильным приложением.

## Принятые решения

### Доступ к переписке с пациентами (14.10.2026)

Заведующий отделением **не получает** автоматического доступа к содержанию
сообщений врачей с пациентами. Сохраняется текущая модель:

- переписка доступна только лечащему врачу и только в пределах его
  разрешённой области доступа;
- остальные роли (заведующий отделением, председатель консилиума,
  руководство) не получают доступа к сообщениям ни через раздел
  «Сообщения», ни по прямой ссылке на диалог, ни через карточку пациента
  или другие разделы;
- новых прав под переписку не вводится.

Прототип уже следует этому решению: пункта «Сообщения» у этих ролей нет,
прямые ссылки показывают «Раздел недоступен», кнопки переписки в карточке
нет, текст сообщений на их страницах не выводится. Изменение модели —
только отдельным решением.

Файлы: `index.html` (каркас), `styles.css` (токены и компоненты),
`app.js` (экраны, роли, окна), `data.js` (синтетические данные).
