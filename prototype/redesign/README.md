# Прототип редизайна «Системы планирования»

Визуальная демоверсия для согласования. Не подключена к backend и API,
работает только на синтетических данных (`data.js`); изменения живут в
памяти вкладки и пропадают при перезагрузке. Основной интерфейс
(`index.html`, `static/`) не изменён.

## Запуск

Из корня репозитория (прототип берёт шрифты из `static/fonts.css`):

```bash
python3 -m http.server 8765 --bind 127.0.0.1
```

Открыть: <http://127.0.0.1:8765/prototype/redesign/>

## Что внутри

- Переключатель «Роль» в верхней панели: врач, заведующий, председатель
  консилиума, руководство. Разделы и кнопки видны по тем же правилам, что
  в приложении.
- Переключатель «Состояние»: данные, загрузка, пусто, ошибка.
- Кнопка с луной — светлая и тёмная тема (по умолчанию — системная).
- Клавиша `/` — фокус на поиске, `Esc` — закрыть окно.

Файлы: `index.html` (каркас), `styles.css` (токены и компоненты),
`app.js` (экраны, роли, окна), `data.js` (синтетические данные).
