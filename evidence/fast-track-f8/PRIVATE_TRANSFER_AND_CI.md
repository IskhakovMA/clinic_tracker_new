## Правила Git для следующих Fast Track

- Публиковать исходники и доказательства только в приватный `IskhakovMA/clinic_tracker_new` через отдельный remote `clinic-private`. Перед каждым push проверить, что репозиторий по-прежнему private и конечная ветка совпадает с разрешенной. Для F8 установлен branch-specific pushRemote.
- Сохранять `origin` на `IskhakovMA/fixes`. Публичный репозиторий используется только для разрешенных обезличенных отчетов.
- Публиковать точный проверенный коммит в отдельную ветку обычным push. Сверять SHA, дерево и SHA-256 артефактов обратным скачиванием до удаления локальных копий.
- Закрытые данные, эксплуатационные журналы, секреты, реальные базы и сведения пациентов исключать из передачи. Уникальные исходные доказательства сохранять до подтвержденного переноса.
- Повторный запуск CI проводится на точном опубликованном SHA. Новый код требует отдельного SHA и собственных результатов. Эта публикация не разрешает merge или deploy.
